# داشبورد تصمیم‌گیری کارخانهٔ پودر باریت سایا

نشانی: https://nspresource-dotcom.github.io/sanico-dashboard/barite/

- ورود با همان حساب داشبورد مالی سایا نیک (Supabase، پروژهٔ zlzjzzqrkbsqornnimlx).
- داده‌ها در جدول‌های `bf_model`، `bf_scenarios`، `bf_production`، `bf_sales`، `bf_purchases`، `bf_expenses`؛
  خواندن برای کاربر فعال، نوشتن فقط برای نقش admin (RLS).
- `engine.js` موتور محاسبه است — همان منطق فایل امکان‌سنجی HTML و گوگل‌شیت؛ مبالغ داخلی به تومان.
- `plan.js` پایش ۱۹ بُعد، دروازه‌ها و اقدام‌ها، درخت ارزش و پیش‌بینی ۱۳ هفته‌ای (از نقشهٔ راه رشد ۵ ساله).
- `app.js` رابط کاربری؛ `jalali.js` تقویم شمسی (از کارنما).
- بدون مرحلهٔ build: فایل‌ها را ویرایش و push کنید، GitHub Pages منتشر می‌کند.
