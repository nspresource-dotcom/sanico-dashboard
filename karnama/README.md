# کارنما — نسخهٔ نمایشی

رابط کاربری سامانهٔ مدیریت کار، ساعت کاری و بهره‌وری واحدها.

**این فقط نسخهٔ نمایشی است.** سرور و پایگاه داده‌ای در کار نیست؛ همهٔ
داده‌ها ساختگی‌اند و در مرورگر خودِ شما (`localStorage`) می‌مانند.
هر کاری اینجا بکنید فقط روی دستگاه خودتان اثر دارد و با پاک کردن
دادهٔ سایت، همه‌چیز به حالت اول برمی‌گردد.

## ورود

| نام کاربری | نقش |
|---|---|
| `modir` | مدیر ارشد — همهٔ بخش‌ها |
| `ali` | مدیر واحد — کارتابل بررسی و بهره‌وری واحد |
| `sara` | کارشناس آزمایشگاه |
| `nazanin` | کارشناس اداری — برای دیدن محرمانگی بین واحدها |

رمز عبور در نسخهٔ نمایشی بررسی نمی‌شود؛ هرچه بنویسید وارد می‌شوید.

## نصب روی گوشی

**اندروید (کروم):** منوی سه‌نقطه ← Add to Home screen
**آیفون (سافاری):** دکمهٔ اشتراک‌گذاری ← Add to Home Screen

بعد از نصب، مثل یک اپ باز می‌شود و آفلاین هم کار می‌کند.

## رنگ و فونت

پالت از لوگوی سایا (`#387F81`) گرفته شده و به‌عمد رنگ غالب نیست:
زمینه روشن و خنثی می‌ماند و سبزآبی فقط روی کنش اصلی، آیتم فعال و
نقطهٔ تأکید داده می‌نشیند. فونت وزیرمتن است با فالبک به فونت‌های
فارسی نصب‌شده روی خود دستگاه.
